# Contributing

Contributions, experiments, and forks are welcome.

## Useful contribution areas

- Accessibility and keyboard navigation
- Audio stability across browsers
- New procedural transmission sites
- Additional Canvas rendering modes
- MIDI or microphone input
- Performance improvements
- Mobile layout refinements

## Development

1. Fork the repository.
2. Create a focused branch.
3. Run the project through a local static server.
4. Test in a current Chromium, Firefox, or Safari browser.
5. Submit a pull request explaining both the technical and experiential change.

Please preserve the fictional archival framing unless a fork intentionally establishes a new direction.
